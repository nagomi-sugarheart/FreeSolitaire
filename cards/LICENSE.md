# カード画像について

`cards/` の SVG 画像は Adrian Kennard 氏のトランプデザイン（https://www.me.uk/cards/ ）を元にしたものです。
npm パッケージ [@letele/playing-cards](https://github.com/letele/playing-cards)（CC0 1.0）に含まれる React コンポーネントから SVG を書き出しています。
