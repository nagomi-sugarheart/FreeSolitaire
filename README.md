# フリーソリティア

ブラウザで遊べる無料のソリティアです。**クロンダイク**（`index.html`）と**フリーセル**（`freecell.html`）が遊べます。インストール不要・サーバー処理なしの静的サイトです。

## 特徴

- **配置はその場で生成**：約43億通り（32bitのゲーム番号）の中からランダムに配ります。
- **クリア不可能な配置は出ない**：配る前に内蔵ソルバーが実際に解けることを確認し、解けた配置だけを配ります（Web Worker で裏側で計算するので画面は止まりません）。
- クロンダイク：1枚引き / 3枚引き、山札の戻しは無制限
- フリーセル：まとめて移動（スーパームーブ）対応、不要になったカードは自動で組札へ
- ドラッグ操作・クリックで自動移動・元に戻す・ヒント（ソルバーが次の一手を提示）
- 全カードが表になると自動で完成
- 成績（勝率・連勝・ベストタイム）と途中のゲームをブラウザに自動保存
- ゲーム番号を指定して同じ配置を遊べます
- カードのデザインは「クラシック（絵札あり）」と「シンプル（大きな文字）」をメニューで切り替え可能

## 遊び方（ローカル）

Web Worker を使うため、HTTP サーバー経由で開いてください。

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

（`index.html` を直接開いても動きますが、配置の確認がメインスレッドで行われます）

## 公開（GitHub Pages）

リポジトリの Settings → Pages で「Deploy from a branch」→ `main` / `(root)` を選ぶと公開されます。

## ファイル構成

- `common.js` / `style.css` … 両ゲーム共通（カード表示・保存・ソルバー呼び出しなど）
- `index.html` / `app.js` / `engine.js` / `solver.js` … クロンダイク（ソルバーは深さ優先探索＋局面の重複排除）
- `freecell.html` / `freecell.js` / `fc-solver.js` … フリーセル（ソルバーは最良優先探索）
- ソルバーは Web Worker としても、画面側でも動作します
- `cards/` … カード画像（Adrian Kennard 氏のデザイン、CC0／パブリックドメイン。詳細は `cards/LICENSE.md`）
